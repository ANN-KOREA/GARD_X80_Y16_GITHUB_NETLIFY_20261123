## 기록 이전 순서

1. 기존 사이트의 **로컬 기록 → 전체 내보내기**로 `x80-y16-history.json`을 저장합니다.
2. 저장하지 않은 현재 입력이 있으면 기존 사이트의 **JSON**을 눌러 별도로 저장합니다.
3. 새 앱의 **입력·계산 → JSON / CSV 가져오기**에서 전체 기록 JSON을 선택합니다.
4. 새 앱의 **로컬 기록**에서 개수·대상자 키·날짜를 확인합니다.
