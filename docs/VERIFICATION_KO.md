## 검증 범위의 한계

GitHub 원격 저장소 생성·Push와 Netlify 실제 배포는 수행하지 않았습니다. Netlify의 실제 CDN 응답 헤더·계정 접근제어·자동 배포 성공 여부는 실제 배포 후 확인해야 합니다. 이번 브라우저 검증은 개발 미리보기의 데스크톱 화면이며, 여러 모바일 기기·보조공학 도구에 대한 전수 시험은 아닙니다. 반응형 CSS와 키보드 focus 표시는 포함했습니다.

원본에 포함된 학습수·Locked Holdout Exact·Within ±1 등은 기존 메타데이터입니다. 원본 학습·검증 데이터가 없으므로 해당 연구 성능을 새로 계산하거나 임상적 타당성을 검증하지 않았습니다. 학습 완료 모델의 추론 재현 확인을 임상검증으로 해석하면 안 됩니다.

원본 레지스트리에 이미 기록된 `embeddedMasterMatches: false`와 archive SHA의 차이는 그대로 보존했습니다. 이번 검사에서 확인한 것은 배포용 portable `.bin`의 실제 SHA입니다. 원본 ZIP·MASTER 문서를 다시 확보하거나 그 불일치를 해소한 것은 아닙니다.
